# Twenty-fifth slice: enemies, drips and full-renderer evidence

The continuous renderer planner now reaches BC5E, after enemy and drip drawing.
All 75 captured entry-to-actor intervals match in Python and Godot: 1,167
generated graphics calls, every call's arguments and entry/pre-return hardware
checkpoints, overall timing, and the resulting enemy animation state.

## Actor work

The enemy loop is BA38..BBA0. It skips state 24, applies the original asymmetric
visibility bounds, and looks up the sprite frame through DS:021D using the
enemy's animation index. Normal drawing uses a mask and color pass. Idle state
-1 advances the animation index only after a visible draw and wraps after 11.
Other states retain their original branch rules, including the old-page test
for the mask-only path; those branches are not native-verified by this route.

The drip loop is BBA0..BC5E. It applies its own strict viewport bounds and emits
mask/color draws for the selected drip frame. Its projection differs from the
enemy's bottom-anchored image. The rendering loop itself does not advance the
drip frame.

The observer records live enemy/drip arrays and the 12-entry enemy frame map.
At renderer entry it also records an image-header bank for the relevant enemy
types and drip frames. The planner selects headers and far-pointer arguments
from initial state, never from later captured draw calls. Generated pointer
offsets use the signed-word representation used by the native argument probes;
the masked-sprite helper interprets their actual 16-bit values.

## Native coverage

Authoritative capture:
`testing/output/wr1_actors_observed_native.json/.jsonl/.map`. Fixture:
`testing/fixtures/wr1_renderer_actors.json.gz`, generated by
`prepare_wr1_renderer_actors.py`. The stage probe is renderer 0812:113E, file
BC5E.

The route contains two type-2 enemies, both in idle state -1 throughout these
samples. There are 34 visible enemy draws (68 image passes), 34 animation-index
changes and two index wraps. Offscreen enemies preserve their animation index.
There are 12 visible drip draws (24 image passes); recorded drip frame states
include 0, 1 and 2. Other enemy types, non-idle states, additional clipping
combinations and later drip frames still need native coverage.

Together with prior sections, the 75 intervals generate 724 copies, 234 masked
sprite calls, 75 drawing-page selections, 75 fill-style changes and 59 filled
rectangles. Durations span 24,307..58,882 guest cycles. These are renderer
intervals including transition invocations, not 75 complete ordinary updates.

The first probe build failed on C++ tokenization of a hex literal ending in E
immediately followed by `+2`. That was corrected. The earlier
`wr1_actors_work_native` capture used the previous core and is retained only as
a diagnostic; it is not the fixture source. The authoritative capture was made
after the corrected build completed and its matching link map was preserved.
