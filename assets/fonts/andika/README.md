# Andika 7.000

Unmodified `Andika-Regular.ttf`, distributed with its SIL Open Font License in
`OFL.txt`. No system font installation or network connection is needed to play.

- Design: https://software.sil.org/andika/design/
- Release: https://github.com/silnrsi/font-andika/releases/tag/v7.000
- Download: https://github.com/silnrsi/font-andika/releases/download/v7.000/Andika-7.000.zip
- Font SHA-256: `27484fdc98d0d63f90407f8266e28295f6fb16d2b13c5024df0214f17152919a`

Andika was designed for literacy materials and beginning readers. This is a
reason for choosing it, not a claim that any font guarantees improved reading.

`metrics.json` records the unmodified font's units-per-em and the union of its
`glyf` bounds for `a-z`, `A-Z` and `0-9`, extracted with FontTools. These bounds
include descenders and give the original English vocabulary a stable baseline
with padding, without shrinking text to fit the font's multilingual line spacing.
New vocabulary using other scripts or diacritics will need expanded metrics.
